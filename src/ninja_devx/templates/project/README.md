# {{ project_name }}

A ninja-devx project, generated by `manage.py devx_startproject`.

```bash
python manage.py migrate
python manage.py runserver   # http://127.0.0.1:8000/api/docs
pytest -q
```

`config/api.py` builds the `NinjaAPI`: request ids, security headers and hardening
middleware (max body size, allowed media type, JSON nesting depth) are installed through
`ninja_devx.plugins.install`, errors map through `ErrorMap.django_defaults()`, and
`/api/health/live` and `/api/health/ready` are mounted for load balancers and
orchestrators. `config/settings.py` logs JSON lines to the console and reads the database
from `DATABASE_URL` (SQLite by default).

## Configuration

Copy `.env.example` to `.env`, export its variables, or set them however you deploy:

| Variable | Default | Purpose |
|---|---|---|
| `DJANGO_SECRET_KEY` | a key generated for this project | Django's cryptographic signing |
| `DJANGO_DEBUG` | `True` | Django's debug mode |
| `DJANGO_ALLOWED_HOSTS` | `localhost,127.0.0.1` | comma-separated allowed hosts |
| `DATABASE_URL` | unset (SQLite `db.sqlite3`) | `postgresql://user:password@host:5432/name` |

## Local PostgreSQL

`docker compose up -d` starts a local PostgreSQL matching `.env.example`; `docker compose
down` stops it. Point `DATABASE_URL` at it, or leave it unset to use the default SQLite
database.
